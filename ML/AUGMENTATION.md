# Аугментации и сравнение детекторов

Обучение на RTX 4050 завершено. Выбран аугментированный YOLO11n: val mAP50–95 0.265 против 0.246 у контроля; test mAP50–95 0.189. Веса — `models/cash_detector/best.pt` и `last.pt`. Подробные результаты, пропуски и ограничения: [RESULTS.md](RESULTS.md).

Аугментации применены **после разделения данных и только к train**. Для каждого из 45 исходных обучающих изображений сохранены четыре варианта, вместе с оригиналами — 225 train. Val: 10, test: 6, без изменений. Итого 241 изображение, 841 бокс. Это 61 исходное изображение и 180 производных вариантов, а не 241 независимая сцена.

| Вариант | Преобразование |
| --- | --- |
| dark | Умеренное затемнение, gamma 1.08, слабый шум со стандартным отклонением 1.2/255 |
| bright | Умеренное осветление, gamma 0.98, такой же слабый шум |
| mirror | Горизонтальное отражение с преобразованием боксов; слабое изменение яркости |
| rotate | Поворот на 1–3° в обе стороны, расширение холста, сохранение всех размеченных объектов |

Поворот преобразует четыре угла каждого бокса и строит ограничивающий прямоугольник. Изображение и боксы отражаются согласованно. Новые области холста заполнены серым. Вертикальные отражения, сильные перспективные изменения, mixup, mosaic и вырезание предметов не используются в этом эксперименте. Горизонтальное отражение допустимо для текущих классов предметов; для будущих правил о расположении зон его нужно пересмотреть.

Файлы: `datasets/cash_objects_aug_v1/`, `data.yaml`, COCO в `coco/`, YOLO в `labels/`, примеры преобразований в `previews/`. В `manifest.json` сохранены родительское изображение, его хеш, исходная группа, вариант и матрица преобразования. Аугментированные боксы имеют статус `derived_from_codex_visual_review`: они получены из исправленных родителей автоматически, а не приняты экспертом заново.

Проверки подтверждают согласованное отражение пикселей и боксов, сохранение объектов при повороте, допустимые координаты, непересечение групп и побайтное совпадение val/test с исходным экспортом.

## Обучение и оценка

Предобученный YOLO11n дообучается на пяти классах, размер входа 640, batch 5, seed 42, AdamW, lr 0.0005 с cosine decay, первые 10 блоков сети заморожены. Дополнительные онлайн-аугментации отключены, чтобы сравнить подготовленные варианты. Обучаются два запуска с одинаковым числом шагов оптимизатора:

- С аугментациями: 225 train × 20 эпох / batch 5 = 900 шагов.
- Контроль без аугментаций: 45 train × 100 эпох / batch 5 = 900 шагов.

В каждом запуске сохраняются `best.pt` и `last.pt`, журнал эпох и параметры. Выбор между запусками — по mAP50–95 на исходной val. После выбора выполняется отдельная оценка выбранной модели на test; test не используется для выбора модели. Сравнение исследовательское: один seed, у контрольного запуска больше промежуточных проверок val, а learning-rate schedule меняется с другой частотой по шагам. Оно не доказывает универсальный эффект аугментаций.

Для детекции считаются mAP50 и mAP50–95, отдельно для каждого класса. Также сохраняются TP/FP/FN, precision и recall при фиксированных confidence=0.25 и IoU=0.5, предсказания JSON и изображения с боксами. Это качество обнаружения предметов, а не точность определения нарушений.

## Воспроизведение

```powershell
# CUDA-сборки под Python 3.11 / Windows; системный драйвер NVIDIA уже установлен.
ML/.venv/Scripts/python.exe -m pip install torch==2.6.0 torchvision==0.21.0 --index-url https://download.pytorch.org/whl/cu124
ML/.venv/Scripts/python.exe -m pip install -r ML/requirements-detector.txt
ML/.venv/Scripts/python.exe ML/augment_detection_dataset.py
ML/.venv/Scripts/python.exe -m unittest discover -s ML -p 'test_*.py'
ML/.venv/Scripts/python.exe ML/run_detector_experiment.py --device 0 --lr 0.0005 --freeze 10
```

Для нового эксперимента указать новый `--prefix`. Завершённые этапы с сохранёнными метаданными при повторном запуске используются повторно. Основные результаты: `runs/detector_comparison.json`, журналы `runs/cash_yolo11n_*.log`, выбранные веса `models/cash_detector/best.pt`, `last.pt`, `model_card.json`. На CPU использовать `--device cpu`; это существенно медленнее.

Для загрузки CUDA-сборок по частям с возобновлением предусмотрен `fetch_cuda_wheels.py`: только официальные файлы под Windows/Python 3.11, итоговый SHA-256 сверяется с индексом PyTorch. Затем устанавливать локальные `.whl` из `cache/wheels/` через pip. Это альтернативный способ скачать те же сборки, а не отдельная установка драйвера.

Автоматическая цепочка скачивания, установки проверенных CUDA-сборок, проверки матричного умножения/NMS на GPU, тестов и обучения — `ML/.venv/Scripts/python.exe ML/setup_gpu.py --train`. Если загрузчик уже работает отдельно, добавить `--wait-for-download`, чтобы дождаться его файлов. Зависимости из `requirements-detector.txt` должны быть установлены заранее.

Параметры донастройки выбраны по двум предварительным CPU-пилотам на 384 пикселях, одинаковых данных с аугментациями, 20 эпохах и seed 42: полное дообучение с lr=0.0015 дало val mAP50–95 ≈0.181; freeze=10 и lr=0.0005 — ≈0.269. Test в пилотах не использовался. Это выбор конфигурации для дальнейшего GPU-сравнения, а не доказательство эффекта одной только заморозки.

Локальный инференс выбранного детектора на исходном видео:

```powershell
ML/.venv/Scripts/python.exe ML/predict_objects.py "ML/open/open/videos/Х-1.mov" --roi 0 300 464 610 --device 0 --output ML/runs/object_example
```

Таймкоды берутся из PTS через PyAV. Боксы в JSON возвращаются к координатам исходного кадра. Для уже обрезанного изображения `--roi` не указывать. Геометрия этой области подходит исходной камере; для другого ракурса нужно задать свою. После загрузки зависимостей и весов обучение и инференс работают офлайн, проверки обновлений и внешние интеграции отключены.

Описание параметров и метрик сверено с [официальной документацией аугментаций Ultralytics](https://docs.ultralytics.com/guides/yolo-data-augmentation/) и [валидации Ultralytics](https://docs.ultralytics.com/modes/val/). Совместимая пара CUDA-сборок приведена в [официальных инструкциях PyTorch 2.6](https://pytorch.org/get-started/previous-versions/). Условия YOLO11n: AGPL-3.0, ссылка сохранена рядом с весами; атрибуция внешних изображений сохранена в наборе.
