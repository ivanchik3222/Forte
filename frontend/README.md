# Фронтенд Forte Control

React, TypeScript, Zustand. Рабочий режим подключается к Flask: JWT-сессия восстанавливается после обновления страницы, видео сохраняются на сервере, история и события загружаются через API.

`npm ci`, затем `npm start`. API по умолчанию: `http://localhost:6767`; другой адрес задаётся `REACT_APP_API_URL` без `/api` при сборке. Cookie/CORS и запуск сервера описаны в [RUNBOOK](../docs/RUNBOOK.md), запросы — в [контракте API](../docs/API_CONTRACT.md).

После входа доступны обзор, история, загрузка MOV/MP4/WebM до 200 МиБ, просмотр видео, JSON, оповещения и справочник источников. Статус сохранённого видео — «Без анализа». ИИ-анализ и потоки камер пока не подключены. Демо включается отдельно на главной, на экране входа или в настройках; его записи не попадают в рабочую БД. Ошибка API не включает демо автоматически.

Рабочие экраны находятся в `src/features/workspace/`, DTO и адаптеры — в `src/api/workspace.ts`, общий клиент с refresh — `src/api/client.ts`. Демо использует прежние analysis/notification компоненты и stores. Старый адаптер `features/analysis/api.ts` сохранён для будущего контракта жюри, рабочий интерфейс его не вызывает.

Списки фильтруются и разбиваются на страницы сервером. Просмотр событий персонален; «Отметить показанные» относится только к текущей странице. Короткую ссылку на оригинал можно обновить из карточки. MOV с неподдерживаемым браузером кодеком можно скачать.

Проверки:

```text
npm test -- --watchAll=false --runInBand
npx tsc --noEmit
npm run build
```

CSS генерируется при start/test/build. `src/styles/generated.css` и `build/` не коммитятся. Nginx использует SPA fallback для прямых ссылок.

## Дизайн и источники

Фирменный ориентир — [официальный сайт ForteBank](https://forte.kz): логотип, основной цвет `#A31551`, тёмный бордовый `#4A0221`, Open Sans. Учтены локальные материалы `design rules`: единая сетка, визуальная иерархия, свободные отступы, сдержанные тени. Шрифты и изображение включены в сборку; внешние ресурсы при обычной работе не загружаются.

Hero-изображение с объективом и четыре объёмные иллюстрации в палитре бордовый/голубой сгенерированы специально для оформления проекта. Иллюстрации карточек поставляются в WebP, в двух размерах, с отложенной загрузкой и прозрачным фоном. Это декоративный визуал, не кадр видеонаблюдения. Изображение кассы в демо сгенерировано и прямо обозначено как синтетическая иллюстрация.

Нормативный источник: [постановление Правления НБРК от 29.11.2019 № 231](https://adilet.zan.kz/rus/docs/V1900019680). Фронтенд не выполняет юридическую классификацию. Актуальную редакцию, применимые пункты и сопоставление событий должна проверить команда.
