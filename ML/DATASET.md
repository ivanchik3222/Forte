# Исправленные боксы для первого обучения

Итоговый набор находится в `ML/datasets/cash_objects_v1/`: **61 изображение, 233 бокса**. Форматы YOLO Detection и COCO Detection. Подготовлен 17 октября 2026 года. Это небольшой стартовый набор для детектора предметов; разметка просмотрена Codex визуально, экспертного подтверждения нет.

## Классы и границы объектов

| YOLO ID | COCO/Torchvision ID | Класс | Что размечено |
| ---: | ---: | --- | --- |
| 0 | 1 | person | Видимая часть реального человека внутри обрезки, включая видимые руки. Кассир и посетитель объединены. Отражения не целевые объекты. |
| 1 | 2 | hand | Видимая кисть и пальцы, без всего предплечья. Две различимые кисти — два бокса. |
| 2 | 3 | cash | Различимые банкноты или пачка банкнот. Кассовый ящик, обычная бумага и чашки не считаются деньгами. |
| 3 | 4 | bag | Сумка, включая ручки; допускается сложенная или частично перекрытая сумка. Кошельки из дополнения исключены. |
| 4 | 5 | storage_cabinet | Видимая металлическая часть шкафа для хранения. Бокс не подтверждает, что это сертифицированный сейф, и не задаёт состояние замка. |

Классы `Gun`, `Pocket`, `Counter`, `Register` из Roboflow не перенесены. Двери, телефоны и чашки пока не включены: для них нет достаточной исправленной разметки. Боксы не являются классами нарушений. Для событий понадобятся временные интервалы, траектории и подтверждённые правила.

Из 42 исходных роликов получено 40 уникальных по SHA-256. Взято 41 изображение: по одной точке из каждого уникального видео, у дубликата Х-4/Х-47 сохранены обе разные временные отметки. У положительных видео использованы исходные отметки событий, у отрицательных — середина. Не каждый момент видео размечен.

Копии одного видео и вручную сгруппированные похожие сцены остаются в одной выборке. Похожие кадры Roboflow также сгруппированы; всё внешнее дополнение используется только для обучения. Близость сцен определена визуально, а не датами съёмки: даты неизвестны. Все отложенные кадры ForteBank имеют исходную камеру, поэтому это ещё не независимая оценка новой камеры.

## Изображения и координаты

Кадры ForteBank обрезаны до рабочей области исходного кадра **[0, 300, 464, 610]**, итоговый размер **464×310**. Так исключена большая часть верхних отражений. Для возврата боксов к исходному видео прибавить 300 к координатам Y; X не меняется. При инференсе на этих видео использовать ту же обрезку. Для нового ракурса потребуется другая область.

Неоднозначные мелкие предметы в отмеченных областях закрашены серым `(114,114,114)` перед экспортом, чтобы не навязывать им неправильный класс. Эти области сохранены в `manifest.json` как `ignore_regions_masked`. Это обработка пикселей, а не поддержка ignore-region в loss. Исходные видео и извлечённые кадры сохранены отдельно без такой обработки.

Исправленные координаты в исходных пикселях находятся в `ML/annotations/corrected/manual_boxes.json`; исправления внешних сцен — в `external_manual.json`. При изменении этих файлов запускать `build_detection_dataset.py`, а затем просматривать новые превью. `prepare_detection_frames.py` повторно извлекает кадры, а не восстанавливает ручные боксы. Не использовать предложения DINO как готовую истину.

[Roboflow Cash Counter Theft v2, Ayaan](https://universe.roboflow.com/ayaan-falfl/cash-counter-theft/dataset/2): скачаны 259 изображений, после отбора использованы 8. Заявленная лицензия CC BY 4.0. Только скачивание публичного датасета; кадры ForteBank в Roboflow не отправлялись.

Исключены кадры с неразмеченным человеком/рукой, деталью ремня и кошельком. Это преимущественно предметные фотографии сумок: они расширяют внешний вид класса, но отличаются от банковского видео. Индивидуальные авторы, исходные ссылки и лицензии CC BY сохранены в `ATTRIBUTION.md` и `manifest.json`. Аннотации Open Images — Google LLC, CC BY 4.0.

## Использование

Из корня проекта:

```powershell
ML/.venv/Scripts/python.exe ML/build_detection_dataset.py
ML/.venv/Scripts/python.exe -m unittest discover -s ML -p 'test_*.py'
```

YOLO: конфигурация `ML/datasets/cash_objects_v1/data.yaml`, изображения `images/`, нормированные боксы `labels/`. Ultralytics в текущем окружении не установлен. COCO: `coco/train.json`, `val.json`, `test.json`; `file_name` разрешается относительно папки `coco/`. Для Torchvision уже готов загрузчик:

```python
from torch.utils.data import DataLoader
from detection_data import CashDetectionDataset, collate_detection

dataset = CashDetectionDataset("ML/datasets/cash_objects_v1", "train")
loader = DataLoader(dataset, batch_size=2, shuffle=True,
                    collate_fn=collate_detection)
images, targets = next(iter(loader))
# images: RGB float32 [0, 1]; targets: boxes XYXY, labels 1..5.
# Для детектора Torchvision num_classes=6 с учётом background.
```

Импорт `detection_data` рассчитан на скрипт из папки `ML` или добавление `ML` в PYTHONPATH. После переноса проекта пересобрать экспорт: путь в `data.yaml` абсолютный. Превью всех экспортированных изображений с боксами находятся в `previews/`, общие листы — `sheet_01.jpg`…`sheet_08.jpg`.

Набор и исходные данные исключены из Git. Для переноса разметки сохранить отдельно `annotations/corrected/`, `datasets/cash_objects_v1/` и `ATTRIBUTION.md`; `.env` переносить только через безопасное локальное хранение секретов.

На этом наборе выполнены донастройка предобученного YOLO11n, сравнение аугментаций и отдельная оценка выбранных весов на test: [RESULTS.md](RESULTS.md), [AUGMENTATION.md](AUGMENTATION.md). Данных пока мало: особенно нужны дополнительные чёткие банкноты, сумки на банковской камере и разные состояния/видимые части шкафа. Для анализа нарушений также нужна разметка последовательностей действий; увеличение числа похожих кадров само по себе её не заменит.
