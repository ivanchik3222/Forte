# Замороженная банковская модель

`bank_only.npz` — точная копия выбранной головы из `runs/mac_reviewed_v1`;
SHA-256 `f4f1a06a7296d63a3ea6f95a1da7e50ea41f84c1348648713142c861c4070902`.
Формат содержит численные массивы и JSON, загрузка выполняется с allow_pickle=False.
Энкодер R3D18 Kinetics400 остаётся замороженным, два вида: стол и полный кадр.
Входная камера: 464×848, порог 0,5. Параметры не менялись при подключении к API.

Энкодер не включён в Git. Подготовка из корня:
`ML/.venv/bin/python ML/download_models.py --r3d`.
Официальный файл: https://download.pytorch.org/models/r3d_18-b3b3357e.pth .
SHA-256: `b3b3357ead25631ec9c57362ff2128a92d0427e01e2cd184951a44380c3f2e9d`.
Инференс не скачивает веса; код энкодера предоставляется установленным torchvision.

В `model_bundle.json` сохранены измерения по группам сцен на 38 development-видео:
accuracy 0,6579, precision 0,6522, recall 0,75, F1 0,6977. Это метрики выбора
варианта, не независимый финальный тест и не качество распознавания типа события.
Х-16/Х-17 исключены из обучения и подбора порогов. Сервер разрешает только
инференс и записывает факт использования в `candidate/test-use.json`.
Исследовательский CLI требует явного `--allow-reserved-test`.

Результат головы — кандидаты с таймкодами и некалиброванным score. Поля type и
rule_id остаются null; нормативные нарушения не определяются автоматически.
Слабая голова отдельных действий не используется в рабочем API. Текстовые
наблюдения формирует отдельно локальная Qwen3-VL-4B без старого LoRA-адаптера.
